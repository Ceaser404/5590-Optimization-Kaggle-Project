# 5590-Optimization-Kaggle-Project
Submissions to UMKC's 5590 Optimization class Kaggle competition final project. Class was taught by Shuhao Cao.

Summary
Overview

This is the in-class final project of CS 5590/Math 5555 at UMKC for the Fall 2025 semester.

We will use the techniques learned in class to train a large Convolution Neural Network (CNN) to classify the Hiragana characters in Japanese. We may use any set of techniques that you would like to try mentioned on the project page on Canvas.
Data

The dataset we will use is Kuzushiji-MNIST, similar to the handwritten digits dataset MNIST. Please follow the starter code on Kaggle to import the data to a notebook, and generate a sample answer see if you can get the system to grade your submission.
Teams

Each team will consist at most 2 members (solo is good as well), please sign up teams on the Canvas group function in the People tab.
Submission

Please refer to Rules: you can upload .csv files generated by the starter code to this competition. The submission is then cross-validated by using about 50% of the testing dataset. There is a benchmark solution using a default gradient descent optimizer with hyperparameters untweaked, which achieves about 95% accuracy on the testing dataset. Your solution should at least beat this benchmark.
